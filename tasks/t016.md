# t016: AgentClass 配置扩展

## 目标

扩展 AgentClass 系统，支持更丰富的配置，并定义 `Codex` 类作为示例。

## 背景

当前 `AgentClass` 已有基础结构：
- `packages/opencode/src/hydra/agent/class.ts` — 类定义和注册
- `packages/opencode/src/hydra/config.ts` — 配置加载
- `packages/opencode/src/hydra/agent/prompts/` — 内置提示词

现有内置类：`Coder`, `Architect`, `Writer`, `Reviewer`

## 需求

### 1. 扩展 AgentClass.Info schema

添加以下可选字段：

```typescript
export const Info = z.object({
  name: z.string(),
  description: z.string(),
  prompt: z.string(),
  defaultModel: z.string(),
  defaultThinking: Thinking,
  // 新增字段
  workflow: z.string().optional(),        // 工作流程描述（给人看的）
  systemPrompt: z.string().optional(),    // 额外的系统提示词（追加到 prompt）
  tools: z.array(z.string()).optional(),  // 允许使用的工具列表
  timeout: z.number().optional(),         // 该类的默认超时（秒）
  retryOnFail: z.boolean().optional(),    // 失败时是否重试
  maxRetries: z.number().optional(),      // 最大重试次数
})
```

### 2. 定义 Codex 类

在 `BUILTIN` 中添加 `Codex` 类，基于 Codex 的实际工作流程：

**Codex 的特点：**
- 模型：`openai/codex`（或 `openai/gpt-5.2-xhigh`）
- 思考级别：`high`（Codex 会深度思考）
- 超时：`7200`（2小时，Codex 很慢）
- 工作流程：
  1. 阅读任务文档（`tasks/tXXX.md`）
  2. 分析现有代码结构
  3. 制定实现计划
  4. 逐步实现，边做边测试
  5. 完成后自我审查
  6. 不要提交 git（由主控处理）

**提示词要点：**
- 你是 Codex，一个深度思考的编程 Agent
- 任务文档是你的唯一输入，仔细阅读
- 不要急，慢慢来，质量优先
- 遇到不确定的地方，在代码中添加 TODO
- 不要执行 git commit/push，由主控处理
- 完成后输出 `[TASK_COMPLETE]` 标记

### 3. 创建 Codex 提示词文件

创建 `packages/opencode/src/hydra/agent/prompts/codex.txt`

### 4. 更新配置 schema

确保 `HydraConfig.Class` 支持新字段：

```typescript
const Class = z.object({
  description: z.string().optional(),
  model: z.string().optional(),
  thinking: Thinking.optional(),
  prompt: z.string().optional(),
  // 新增
  workflow: z.string().optional(),
  systemPrompt: z.string().optional(),
  tools: z.array(z.string()).optional(),
  timeout: z.number().optional(),
  retryOnFail: z.boolean().optional(),
  maxRetries: z.number().optional(),
})
```

### 5. 更新 register() 函数

确保新字段能正确合并。

## 验收标准

1. `opencode hydra class list` 显示 Codex 类
2. `opencode hydra class show Codex` 显示完整配置
3. 用户可以在 `.hydra/config.yaml` 中覆盖 Codex 的配置
4. 新字段在 spawn agent 时能正确传递
